## Verification status definitions

- **Not verified:** No issuer record, certificate, completion date, or official credential URL is available in this repository yet.
- **In progress:** Learner confirms active enrollment or ongoing study.
- **Completed — evidence pending:** Learner confirms completion, but issuer verification details are not yet recorded.
- **Verified:** Exact title, issuer, completion date (when available), and official credential URL have been checked against the credential record.

## What to provide to complete the register

For each course/certificate, add the exact title shown on the credential, issuing institution/platform, status, completion date, official share/verification URL, and credential ID if one exists. A certificate screenshot or exported credential record can be used to transcribe the fields; avoid sharing private account credentials.

## Application evidence standard

A credential should link to a relevant artifact that shows application—not merely mention a project by name. Useful evidence includes:
- A concise problem statement and intended audience.
- Requirements, acceptance criteria, and a decision rationale.
- An implementation or reproducible analysis.
- Tests/evaluation and limitations.
- A result with baseline, measurement method, and period—or clearly labeled hypothesis if not yet measured.
